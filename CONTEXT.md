# Paid

Paid coordinates software work from intent gathering through delivery and
operational response. These terms describe its automation authority.

## Language

**Automation phase**:
A stage of responsibility for software work: discovery, issue preparation,
coding, merge, release & deployment, or operations. A phase describes the work regardless of whether
a person or automation starts it.

**Project automation default**:
Standing permission for Paid to perform configured automatic work in an enabled
phase for a project.

**Continuation authorization**:
An explicit, revocable grant to continue particular work automatically through
a chosen delivery endpoint, including phases disabled by project defaults.

**Work item**:
The scoped unit of requested work whose identity continues across its linked
issues, agent runs, and pull requests.

**Responsible phase**:
The phase that owns resolving a request, distinct from the phase where the work
originally arose.
